How referral tracking works

Customer A receives a unique code → gives it to Customer B → B enters it → booking shows the code → when B is marked paid, the referral is counted as a successful paid referral.

Recommended reward: give the new/referring customer the referral benefit only as defined by ADRON. In this demo, the referral code is tracked and the referral reward is counted after payment; the exact ₹ reward can be set later.
