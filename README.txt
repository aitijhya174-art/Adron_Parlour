ADRON DEMO — CUSTOMIZATION
1. Open index.html in a browser to preview the demo.
2. In index.html, change DEMO_WHATSAPP to the real WhatsApp number (country code, no + or spaces).
3. Edit service names/prices in the Services section.
4. Edit offer text in the Offers section.
5. Change colors in the :root CSS variables.
6. Replace the demo QR target with the final public URL after hosting this page.
7. The WhatsApp booking flow is functional once DEMO_WHATSAPP is replaced.
